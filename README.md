## 如何玩
如果你实在不知道怎么玩, 所有的代码都位于include和src文件夹中, 然后你可以自己创建, 复制代码, 然后运行项目(如果你有一个好用的IDE--它们通常都有这样的功能).
### Linux
1. 你需要一个至少支持C90的C编译器, 以及比3.10更先进的CMake. 如果没有, 安装它们.
2. cd到该文件夹下, 然后依次输入下面的指令
```bash
mkdir build && cd build
cmake ..
make
```
然后输入命令
```bash
./wolfarch
```
就可以玩. 上面这样不加参数就是命令行模式. 加参数(最多一个, 多加会忽略)则是文件模式.
例如:
```bash
./wolfarch test.txt
```
如果这么做, 你需要在build文件夹中新建这样一个test.txt的文件, 然后在里面用wolfarch语言写点东西. 然后就可以自动检查你的文件.
